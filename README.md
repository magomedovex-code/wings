# DarkWings — тёмные 3D-крылья вместо элитры (Fabric 1.21.11)

Клиентский мод: элитра выглядит как анимированные 3D-крылья. Хитбокс, физика полёта и сама элитра не меняются: мод меняет только то, как она выглядит.

## Стили
| Стиль | Вид |
|---|---|
| Тёмный дракон | перепонки с прожилками, когти |
| Летучая мышь | кожистые, зубчатый край |
| Демон | тёмно-красные, светящиеся жилы |
| Пустота | чёрные, фиолетовое свечение и звёзды |
| Ворон | чёрные перья с синим отливом |
| Падший ангел | тёмные перья, светящиеся концы |
| Обычная элитра | как в ванилле |

## Управление
- **O**: меню выбора крыльев (клавишу можно поменять в «Управление → DarkWings»)
- в меню: превью тебя в 3D (колёсико над ним крутит модель), кнопки «Раскрыть/Сложить» и «Авто»
- слайдеры «Размер» и «Скорость взмахов»
- «Видно: у всех / только мне»: чьи элитры заменять
- «Свечение»: для Демона, Пустоты и Падшего ангела
- «Без элитры: да»: показывать твои крылья как украшение, даже если элитра не надета

Крылья видны с видом от третьего лица (F5). Другие игроки видят их только если у них тоже стоит этот мод.

## Сборка
Сборка идёт на GitHub автоматически (`.github/workflows/build.yml`): после пуша в `main` готовый `darkwings.jar` появляется в **Releases → latest**.

Локальная сборка: `gradle build` (нужны Java 21 и Gradle 9), jar будет в `build/libs/`.

## Как поменять форму крыльев
Геометрия и текстуры генерируются скриптом `tools/gen.py` (Python + Pillow + numpy):
```
OUT=. python3 tools/gen.py
```
Он заново создаёт `WingModels.java`, PNG-текстуры и превью в `preview/`.
